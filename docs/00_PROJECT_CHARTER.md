# [METI] Project Charter (v0.2)

## 제품 한 줄
METI는 **링크/QR로 공유 가능한 디지털 명함**을 만들고, 상대는 **앱 설치 없이 웹에서 열람/저장**할 수 있는 서비스입니다.

## MVP(=서비스로 이어질 수 있는 베이스)
- 퍼블릭 카드 페이지 `/c/:id` (모바일 최적화)
- 카드 생성/편집/공유(링크/QR)
- 필드별 공개 범위(전화/이메일 숨김)
- 최소 분석(조회수, 유입 src)

## 이번 MVP에서 제외(명확히)
- 팀/조직 관리(enterprise)
- 복잡한 CRM/세일즈 파이프라인
- 고급 템플릿 마켓/스토어

## 주요 리스크
- **개인정보 노출**: 기본값을 “숨김” 위주로 설계하고, 로그에 민감정보가 남지 않게.
- **웹+앱 동시 개발 범위 과대**: 우선 퍼블릭 카드(웹) → 관리자 웹 → 모바일 앱 순으로 진행.
