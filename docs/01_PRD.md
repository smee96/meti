# [METI] PRD (Product Requirements Document) v0.2

## 1) 목표(Goals)
- 3분 이내에 명함 생성 및 공유
- 상대는 앱 설치 없이 열람 가능(모바일 웹 최적화)
- 링크/QR이 안정적으로 동작
- 개인정보/공개 범위 설정 제공

## 2) 타겟 사용자
- 프리랜서/창업자/영업/채용 담당자
- 네트워킹이 잦은 직군(컨퍼런스/미팅)

## 3) 핵심 시나리오
### S1. 명함 생성 → 공유
- 로그인/온보딩 → 정보 입력 → 저장 → 링크/QR 공유

### S2. 상대 열람 → 연락/저장
- 링크 클릭 → `/c/:id` 열람 → 연락 버튼(전화/메일) 또는 vCard 다운로드

### S3. 공개 범위 제어
- 필드별 공개/비공개(전화/이메일) → 저장 → 퍼블릭 페이지 반영

## 4) MVP 기능 범위
### 4.1 계정/인증
- **결정 완료**: 단계적 접근
  - MVP-0: 간단한 세션 기반 인증 (기존 이메일 기반 유지)
  - MVP-1: 이메일 매직링크 추가
  - MVP-2: Google/Apple 소셜 로그인 추가
- 최소 요구: 소유자만 카드 편집 가능

### 4.2 카드 생성/편집
- 템플릿 1종(미니멀)부터 시작
- 모바일 미리보기
- 프로필 필드:
  - 필수: displayName, headline(한 줄 소개)
  - 선택: avatar, phone, email, links(여러 개)

### 4.3 공유
- 링크 복사
- QR 생성(이미지 다운로드)
- (선택) vCard(.vcf) 다운로드

### 4.4 공개 범위/프라이버시
- phone/email 필드 공개 토글
- 카드 상태: public / unlisted / private

### 4.5 최소 분석
- 카드 조회수(누적)
- 유입 소스(src 쿼리) 집계

## 5) 비기능 요구사항
- 성능: 퍼블릭 카드 페이지 LCP 2.5s 목표(모바일)
- 보안/개인정보: 최소수집, private 접근 제어
- 접근성: 모바일 우선, 기본 a11y 준수

## 6) 기술 결정 사항
- ✅ **인증**: 단계적 접근 (세션 기반 → 매직링크 → 소셜)
- ✅ **저장소**: Cloudflare D1 (기존 구현 유지, SQLite 기반)
- ⏳ **vCard**: MVP-1에서 추가 고려
