# [METI] Security & Privacy v0.2

## 1) 기본 원칙
- 개인정보 최소수집/최소보관
- 퍼블릭 페이지는 가능한 한 **노출 최소 기본값**(전화/이메일 기본 숨김 권장)

## 2) 카드 접근 정책
- `public`: 누구나 열람 가능
- `unlisted`: 링크를 아는 사람만(검색/목록 노출 없음)
- `private`: 소유자만(인증 필요)

## 3) 로그 정책
- 전화/이메일 등 민감정보는 로그에 남기지 않음
- 조회수는 집계 이벤트로만 저장(원문 IP/UA 저장 금지)

## 4) 권장 보안 체크
- 입력 검증(링크 URL 스킴, 길이 제한)
- Rate limit(퍼블릭 view 이벤트)
- CSRF/세션 정책(웹 관리자)
